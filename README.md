# Super Moonlight Logistics

Super Moonlight Logistics Company Limited is a trusted freight forwarding partner based in Lagos Island (Mandilas), Nigeria. The website showcases the company's services across air and ocean freight, China importation, customs clearance, cargo consolidation, and local/international delivery.

## Features

- **Responsive Design**: Fully mobile-optimized layout with a modern, professional aesthetic
- **Dynamic Routing**: Single-page application navigation
- **Logistics Gallery**: Detailed gallery showing day-to-day operations
- **WhatsApp Integration**: Direct-to-WhatsApp contact forms and floating action buttons
- **Cookie Consent**: NDPR-compliant cookie consent manager with versioning

## Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, Radix UI primitives
- **Icons:** Lucide React

## Running the Code

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
